# NPAD (Network Path & Application Diagnostics)

NPAD diagnoses a range of common performance issues affecting the [last network mile](https://en.wikipedia.org/wiki/Last_mile) and end-users' systems.

Please cite this data set as follows: **The M-Lab NPAD Data Set, &lt;date range used&gt;. https://measurementlab.net/tests/npad**

**Data** collected by NPAD is available:

* in raw format at [https://console.cloud.google.com/storage/browser/archive-measurement-lab/npad](https://console.cloud.google.com/storage/browser/archive-measurement-lab/npad).

* in BigQuery at [/data/docs/bq/quickstart/](/data/docs/bq/quickstart/).

**Source code** is available at [https://github.com/npad/npad](https://github.com/npad/npad).

**Get more information** at [https://web.archive.org/web/20180714140225/https://www.ucar.edu/npad/](https://web.archive.org/web/20180714140225/https://www.ucar.edu/npad/)
